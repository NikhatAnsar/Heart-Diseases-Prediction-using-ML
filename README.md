# Heart-Diseases-Prediction-using-ML
This project leverages machine learning to predict the probability of heart disease in patients based on their medical data. It includes a real-time prediction system built with Flask and an interactive user interface for ease of use, making it accessible and functional for users with varying levels of technical knowledge.
# Project Overview
The heart disease prediction system is developed using several machine learning models to analyze patient health metrics and assess risk levels. Multiple algorithms such as K-Nearest Neighbours (KNN), Support Vector Classifier (SVC), Decision Tree, and Random Forest were implemented and evaluated. Each model was trained on a curated dataset and assessed based on accuracy and performance to determine the most effective approach. A lightweight Flask-based web application was developed to serve these predictions in real time, providing an end-to-end solution. In addition, the dataset was preprocessed and analyzed thoroughly to ensure the quality of training and testing phases. The web interface was thoughtfully designed to allow users to input their health data and instantly view prediction results in a simple, clear manner.

# Features
The system offers a variety of valuable features. It includes multiple machine learning models, allowing performance comparison to identify the most accurate predictor. The Flask backend provides real-time predictions in a responsive and efficient manner. The frontend is user-friendly, allowing seamless data entry and output visualization. The codebase is structured in a clean and modular way, enabling developers to easily extend or modify components for future improvements or custom use cases. user can also get the report after the prediction. There is chatbot to help with your queries.

# Tech Stack
This project utilizes Python as the primary programming language. Flask is used to build the backend web server and handle requests for model predictions. Scikit-learn is employed to build and evaluate the machine learning models, while data preprocessing and manipulation are handled using Pandas and NumPy. For the frontend, HTML and CSS are used to create a clean, intuitive user interface that simplifies the user experience.

# Dataset
The model is trained on publicly available heart disease datasets obtained from Kaggle, such as the UCI Heart Disease dataset. These datasets include vital health metrics such as age, sex, blood pressure, cholesterol level, fasting blood sugar, chest pain type, resting ECG results, maximum heart rate achieved, and exercise-induced angina. These features are known to be key indicators in assessing the likelihood of cardiovascular disease, and they form the input basis for the machine learning models.
